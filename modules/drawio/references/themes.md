# 风格主题（Style Theme）

> 抽取自 `app/config/skill-elements.json` 的 `themes` 节。
> 用户没指定时默认 **Modern**。决定整体气质（圆角/直角、留白多少、配色饱和度）。

---

## Modern — 现代产品/工程文档（默认）

- **配色**：中性底色 + 1 个 accent（可加 1 个 secondary）。色板小、文字对比高、避免彩虹
- **形状**：圆角矩形（subtle radius）、统一描边、浅色填充、用 swimlane/container 分组
- **布局**：网格对齐、padding/gap 一致、清晰层级、慷慨留白
- **连线**：正交布线 + 显式 waypoints、统一箭头、尽量少交叉
- **避免**：渐变、重阴影、3D 效果、装饰性杂物

## Academic — 论文 / 技术文档 / 电子期刊

- **配色**：中性 + 1 个 muted accent。**必须灰度下也清晰**——不要只靠颜色区分（要用标签或线型）
- **形状**：以矩形为主、最小圆角、白/浅填充、统一线宽、整齐的分组框
- **布局**：严格对齐、均匀间距、稳定的标签位置、在 100% 和 50% 缩放下都要可读
- **连线**：正交 + 显式 waypoints、避免交叉、虚线必须有明确含义并标注
- **避免**：装饰图标、粗描边、重填充、强阴影

## Minimal — 线框图 / 概念图

- **配色**：单色或双色调；颜色少用且一致
- **形状**：基础形状、不用图标、无填充或极淡填充、细描边
- **布局**：元素少、大量留白、短标签、不要密集
- **连线**：直线或简单正交、细线、空心箭头、最少折弯
- **避免**：阴影、渐变、粗边框、复杂形状、视觉噪音

## Custom — 用户自定义

- 完全遵循用户在对话中描述的风格
- 没指定就回退到 Modern
- 严格执行用户提供的品牌色板规则
- 色板小、一致，不要发明颜色
