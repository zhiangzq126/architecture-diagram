# 配色方案（Color Theme）

> 抽取自 `app/config/skill-elements.json` 的 `colorThemes` 节。
> 每个方案给出 `fillColor / strokeColor` 配对，**严格成对使用**。

---

## Default — DrawIO 经典

| 角色 | fill | stroke |
|---|---|---|
| 蓝（主流程、范围管理） | `#dae8fc` | `#6c8ebf` |
| 绿（成功、已完成、进度） | `#d5e8d4` | `#82b366` |
| 黄（决策、警告、风险） | `#fff2cc` | `#d6b656` |
| 红（错误、严重、质量问题） | `#f8cecc` | `#b85450` |
| 紫（文档、外部引用、特殊） | `#e1d5e7` | `#9673a6` |
| 橙（注意、重要提示） | `#ffe6cc` | `#d79b00` |
| 灰（容器、swimlane、分组） | `#f5f5f5` | `#666666` |

## None — 不强制

- 不强制色板，按 theme 决定默认色
- 若用户在对话给了颜色，原样使用
- 整图内部保持一致；对比度足够即可
