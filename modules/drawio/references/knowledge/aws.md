# AWS 云服务图标

| shape ID | 含义 | style 示例 |
|---|---|---|
| `mxgraph.aws4.ec2` | EC2 | `shape=mxgraph.aws4.ec2;fillColor=#F58536;strokeColor=none` |
| `mxgraph.aws4.s3` | S3 存储桶 | `shape=mxgraph.aws4.s3;fillColor=#7AA116;strokeColor=none` |
| `mxgraph.aws4.lambda` | Lambda | `shape=mxgraph.aws4.lambda;fillColor=#F58536;strokeColor=none` |
| `mxgraph.aws4.rds` | RDS 数据库 | `shape=mxgraph.aws4.rds;fillColor=#2E73B8;strokeColor=none` |
| `mxgraph.aws4.vpc` | VPC | `shape=mxgraph.aws4.vpc;fillColor=#7AA116;strokeColor=none` |
| `mxgraph.aws4.application_load_balancer` | ALB | `shape=mxgraph.aws4.application_load_balancer;fillColor=#F58536` |
| `mxgraph.aws4.cloudfront` | CloudFront CDN | `shape=mxgraph.aws4.cloudfront;fillColor=#8C4FFF;strokeColor=none` |
| `mxgraph.aws4.dynamodb` | DynamoDB | `shape=mxgraph.aws4.dynamodb;fillColor=#2E73B8;strokeColor=none` |
| `mxgraph.aws4.api_gateway` | API Gateway | `shape=mxgraph.aws4.api_gateway;fillColor=#8C4FFF;strokeColor=none` |
| `mxgraph.aws4.group` | 分组容器 | `shape=mxgraph.aws4.group;fillColor=none;strokeColor=#AAB7B8` |

通常给 AWS 图标节点设置 `width=78 height=78`（图标方形），标签写在 value 里。
